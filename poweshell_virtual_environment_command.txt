PowerShell virtual environment commands

Create a virtual environment using Python 3.12:
    py -3.12 -m venv iris_mlops_venv

Activate it:
    .\iris_mlops_venv\Scripts\Activate.ps1

If PowerShell blocks activation, allow scripts for this PowerShell session only:
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
Then activate the environment again.

Deactivate the environment:
    deactivate

Recreate the environment (deactivate it first):
    Remove-Item -Recurse -Force .\iris_mlops_venv
    py -3.12 -m venv iris_mlops_venv

Stop tracking the environment in Git (if it was already committed):
    git rm -r --cached -- iris_mlops_venv

Add this entry to .gitignore:
    iris_mlops_venv/

Then commit the change:
    git add .gitignore
    git commit -m "Stop tracking virtual environment"
